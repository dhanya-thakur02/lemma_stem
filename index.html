QUICK REFERENCE

Two ways to reduce a word to its base

Stemming

Chops off word endings using fixed rules. Fast, but the result may not be a real word.

studies → studi  |  running → run
Lemmatization

Looks the word up in a vocabulary, using its part of speech, and returns the dictionary form.

mice → mouse  |  was → be

All answers in these activities use NLTK's Porter stemmer and WordNet lemmatizer. Other stemmers can give different results.
